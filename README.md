# Keyboard Projects

This repository contains a collection of my custom mechanical keyboard projects. All related projects are organized here in their own directories.

Each project includes its own documentation, CAD files, firmware, wiring information, and any additional resources required to reproduce or modify the design.

---

## Projects

| Project            | Description                                             | Status         |
| ------------------ | ------------------------------------------------------- | -------------- |
| **Nexus-58 Mk.I**  | Hand-wired 58-key split keyboard powered by the RP2040. | Done           |
| **Nexus-58 Mk.II** | Hand-wired 58-key split keyboard powered by the RP2040. | In Progress    |
